# Extract log-likelihood from LaMaModel object

Extract log-likelihood from LaMaModel object

## Usage

``` r
# S3 method for class 'LaMaModel'
logLik(object, ...)
```

## Arguments

- object:

  A model fitted using RTMB and obtained via `report(obj)` of class
  "LaMaModel"

- ...:

  Additional arguments (not used)

## Value

An object of class "logLik"
